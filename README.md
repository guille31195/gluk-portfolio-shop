# Gluk Portfolio & Shop

Portfolio and e-commerce website for Gluk (Guillermo Carrasquero) — showcasing original oil paintings, tattoo art, sculpture, and mixed media work, with direct sales of original pieces and prints.

## Folder Structure

- `data/raw/` — original artwork photos, exactly as received/shot. Never edited. Gitignored.
- `data/working/` — intermediate/resized images while processing. Gitignored.
- `data/processed/` — clean, final web-ready images. Committed.
- `scripts/` — Python scripts for image processing, cataloging, and site content generation.
- `reports/` — generated inventory and content reports.
- `docs/` — project documentation.

## Data Sources

- Artwork photos: currently scattered across Google Photos, laptop storage, and external hard drives — TBD which become the canonical source for the site.

## Key Principles

- Brand-coherent design across every page, using the existing Gluk brand kit.
- Site doubles as portfolio (originals for viewing/inquiry) and e-commerce (prints for direct purchase).
