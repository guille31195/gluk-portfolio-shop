## Brand Positioning

- **Public name:** GLUK (used publicly — site, work, press). "Guillermo Carrasquero" reserved for bios, contracts, formal credits.
- **One-liner:** "GLUK creates precise, streetwise images about Caribbean identity, memory and power."
- **Tone:** precise, streetwise, elegant, confrontational, tender, cinematic, technologically fluent.
- **Avoid:** tropical-tourism branding, tattoo-shop clichés, generic streetwear, fake luxury, chaotic collage, paintbrush/palette/signature clichés, excessive aggression, trend-chasing.
- **Design system ("The Rupture"):** compositions start from a controlled, editorial, museum-level grid, then one element deliberately breaks it (an image crossing a margin, a line cutting through type, an uncomfortably close crop, a scale shift). Order = elegance/institution; the rupture = street/tension. This is the core visual principle to carry into page layouts.
